**Remote-server mission admission** ([REMOTE-MISSION-ADMISSION-2026-09-12.md](../REMOTE-MISSION-ADMISSION-2026-09-12.md)).
The gameplay-context policy now distinguishes an established remote
authority from an unknown one (`Context.authority`: true, false, nil) and
admits mission modes under a remote dedicated server to presentation and
stock input (`body_mode`) while leaving the local-authority aim route
(`aim_mode`, `local_mission`) unchanged. The online rules admit missions under
either established authority, so a remote mission uses the same stock-input
route as Psykhanium's online rules and SoloPlay missions: dominant-hand
yaw/pitch/roll and the movement vector written into the stock fixed-frame
input cache that prediction, resend, replay and the server read, with the
server's own firing origin, actions and damage. Every local-authority
override stays off because `is_controller_aim_mode` is false whenever the
online rules are enabled. New mod setting `remote_mission_input` (default
on, read per query) withdraws it without a relaunch. The admission record
names the authority: `DARKTIDEVR_ONLINE_RULES ... authority=remote`.
