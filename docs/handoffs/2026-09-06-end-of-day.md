combat mappings. A Hub overrides subgroup adds `vr_hub_bind_*`, with Same as
combat inheritance. Default right grip opens inventory in the hub and retains
weapon special in combat; every other hub control inherits by default. Movement,
turning, native menu selection/back/scroll and aim-hand choice are unchanged.

physical controls blocked until release, and increment the binding revision.
Directional controls also require neutral. Explicit hub overrides never overwrite
combat settings. Existing user remaps and horizontal-turn reservation are retained.

to stock `UIManager._update_view_hotkeys`; it retains stock mode whitelists,
modal/transition/null-service checks and view validation. Blocked requests expire.

there is deliberately no second UIManager.input_service hook. DMF REPLACES hooks
when this mod registers the same target/method twice. All three stock service
return values and keyboard/mouse routes are preserved.

by this profile code. It chooses combat mappings outside hub; it does not remove
