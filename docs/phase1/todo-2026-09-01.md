## 8. Comprehensive bug hunt

- Continuously inspect all touched and launch-critical paths for stale flags,
  cleanup leaks, ownership ambiguity, invalid state transitions, error masking,
  unsafe nil/unit access, counter overflow, timing-label mistakes and tests that
  pass without exercising their claimed runtime path.
- Re-run the complete Release and Debug non-headset suites after native changes;
  isolate the three headset-only tests rather than treating missing hardware as
  a product failure.
- First finding closed: `analyze-gpu-batch-trace.py` assumed each profiler
  capture key was a physical eye. Current traces can contain both sequential
  render-eye segments under one timing capture, so its heading and comparison
  were misleading. The report now follows terminal render-eye identity and has
  a regression fixture for the combined-capture layout.
- Native fence recovery finding closed: the XR harness checked the D3D12
  device-removed `UINT64_MAX` sentinel only at initial attachment. A ready or
  consumed fence poisoned later could therefore be treated as a newer frame
  and queued as an impossible GPU wait. The harness now checks both fences on
  every frame, drops the dead eye/menu generation, clears correlation and
  readback state, and retries the named producer resources. The standalone
  capture path uses the same fail-closed helper. Release and Debug non-headset
  suites pass 30/30 serially, and a live producer/capture smoke advanced ready
  1 -> 4 across three pairs.
- Launch-cleanup finding closed: `-EnterPsykhanium` previously wrote `enter`
  before protected launch work and never restored the prior one-shot state. A
  deliberate failure before the game executable now restores `consumed`, so a
  later ordinary hub launch cannot inherit an unexpected range transition.
- Test-isolation finding recorded: Release and Debug suites must not run
  concurrently because `shared_head_pose` and `window_capture_recovery` use
  process-global named resources. Concurrent cross-configuration execution
  produced one false failure in each suite; isolated reruns and both complete
  serial suites pass.

  changes. The transport ABI is versioned to v11. Release and Debug non-headset
